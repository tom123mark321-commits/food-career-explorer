# Food Career Explorer

A React + TypeScript + Vite project for exploring food-industry career paths.

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite in your browser.

## Build

```bash
npm run build
```

The production build will be generated in `dist/`.

## Notes

- `node_modules/` is intentionally not committed. Run `npm install` after cloning.
- `dist/` is generated output and is intentionally not committed.
